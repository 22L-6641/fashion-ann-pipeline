COPY/PASTE THESE COMMANDS IN WINDOWS POWERSHELL
Run from the extracted fashion-ann-pipeline-starter folder.
Run one section at a time. Replace example values where indicated.

SECTION 1 — CHECK TOOLS
python --version
git --version

If Git or Python is not installed, install them before continuing.

SECTION 2 — CREATE AND ACTIVATE ENVIRONMENT
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt

If PowerShell blocks activation, use Command Prompt and run:
.venv\Scripts\activate.bat

SECTION 3 — INITIAL GIT COMMITS
git config --global user.name "YOUR NAME"
git config --global user.email "YOUR EMAIL"
git init -b main
git add README.md .gitignore requirements.txt
git commit -m "Initial project setup"
git checkout -b dev
git add src/prepare.py
git commit -m "Add Fashion-MNIST preparation"
git add src/preprocess.py
git commit -m "Add preprocessing and validation split"
git add src/train.py params.yaml
git commit -m "Add configurable ANN training"
git add src/evaluate.py
git commit -m "Add model evaluation"
git add dvc.yaml
git commit -m "Define DVC pipeline"

SECTION 4 — RUN PIPELINE
dvc --version
dvc init
git add .dvc .gitignore
git commit -m "Initialize DVC"

Run all stages:
dvc repro

If successful, inspect:
type metrics.json
Test-Path dvc.lock
dvc status

SECTION 5 — GOOGLE DRIVE REMOTE
1. Create a dedicated folder in Google Drive.
2. Copy the folder ID from its URL.
3. Replace YOUR_FOLDER_ID below with your real ID:
dvc remote add -d gdrive_storage gdrive://YOUR_FOLDER_ID
git add .dvc/config
git commit -m "Configure Google Drive remote"

Authenticate/upload:
dvc push

If Google OAuth blocks the default app, follow the supplied DVC Integration & Troubleshooting Guide to configure a Google Cloud OAuth Desktop client and add your account as a test user. Never commit client secrets or token files.

SECTION 6 — HYPERPARAMETER EXPERIMENT
Before changing parameters, copy the current metric values somewhere safe:
type metrics.json

Open params.yaml and change dense_units from 256 to 128. Then run:
dvc repro
type metrics.json
git add params.yaml dvc.yaml dvc.lock metrics.json
git commit -m "Run v2 hyperparameter experiment"
git tag v2
dvc push

The train and evaluate stages should rerun; prepare and preprocess should be skipped if their inputs did not change.

SECTION 7 — GIT EVIDENCE
git log --oneline --graph --all
git log --stat -3
git log -p -1
git log main..dev
git diff
git diff --staged
git diff main..dev
git diff main...dev

For a stash demo, first make an uncommitted edit to src/preprocess.py:
git stash
git stash list
git switch main
git switch dev
git stash pop

For reset demos, use a disposable branch only:
git switch main
git switch -c scratch-reset
Add and commit a harmless README edit, then:
git reset --soft HEAD~1
git status
git commit -m "Scratch commit"
git reset --hard HEAD~1
git status
Do not use reset --hard on your real work branch.
