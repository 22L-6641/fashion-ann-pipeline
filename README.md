# Fashion-MNIST ANN Pipeline

A reproducible Fashion-MNIST classification project using a fully connected TensorFlow ANN, Git, DVC, and Google Drive.

## Quick start (Windows PowerShell)

1. Extract this folder and open PowerShell in it.
2. Run the commands in `RUN_ME_FIRST_POWERSHELL.txt` one section at a time.
3. Create your Google Drive folder and configure the DVC remote when prompted by the assignment workflow.

Run the full ML pipeline (all stages) with `dvc repro`.

The ANN is deliberately fully connected (not a CNN). Results depend on the environment and training time; do not claim a target accuracy unless your measured metrics achieve it.
